# T6 In-process cache: per-entry TTL, LRU at fixed capacity, concurrent, over a slow loader

## First, the honest recommendation
In production I would use **Caffeine** (`Caffeine.newBuilder().maximumSize(n).expireAfter(...).build(loader)`): it does all of this, is heavily tested, and its eviction policy beats plain LRU. Below is the core of a hand-rolled version, which is what the question asks for, and is the right size for understanding what Caffeine is doing for you.

## Requirements for this slice
1. `get(key)` returns the cached value if present and not expired, else loads it via `load(key)` (~50 ms), caches it, returns it.
2. `put(key, value, ttl)` with a per-entry TTL; loaded entries get a default TTL.
3. At most `capacity` entries; inserting beyond that evicts the least recently used.
4. Safe under many concurrent `get`/`put` threads.
5. Because the load is slow: **no lock is held during a load**, and **concurrent misses for the same key trigger one load** (no stampede on the DB).
6. A `put` or `invalidate` that happens while a load is in flight must win; the older loaded value must not overwrite it.
7. A failed load is not cached and is reported to every waiter.

Assumptions: capacity is in the thousands to low millions; values are not null (a null from the loader means "not found" and is not cached; negative caching is a later option); time comes from an injectable nanosecond ticker so tests don't sleep.

## Data structures
| Structure | Purpose | Guarded by |
|---|---|---|
| `LinkedHashMap<K, Entry>` in access order | O(1) lookup + LRU order; `removeEldestEntry` evicts | one `ReentrantLock` |
| `Entry(value, expiresAtNanos)` | per-entry TTL | immutable |
| `ConcurrentHashMap<K, CompletableFuture<V>> inFlight` | single-flight: one load per key, others wait on the future | its own atomic ops, plus the lock at hand-off |

Why one lock and not a `ConcurrentHashMap` alone: in an LRU cache every **read is a write** (it moves the entry to the MRU end), so a plain concurrent map can't keep exact LRU order. The lock is held only for O(1) pointer moves (well under a microsecond), never for the 50 ms load, so contention is low. If profiling ever shows contention, stripe into N independent segments by key hash (each with capacity/N; LRU becomes approximate) or switch to Caffeine, which records reads in lock-free buffers and replays them.

## Correctness tests (before code)
- Miss loads, hit does not: `get(k)` twice -> loader called once, same value.
- TTL: put with ttl 10 s; at t+9.999 s hit; at t+10 s miss and reload. Per-entry: two keys with different TTLs expire independently.
- LRU: capacity 2; put a, put b, get a, put c -> b evicted, a and c present. Size never exceeds capacity.
- Updating an existing key does not evict anything and refreshes its TTL and recency.
- Single-flight: 100 threads `get(k)` simultaneously on a cold key with a 50 ms loader -> loader called exactly once, all 100 get the value.
- Different keys load in parallel: 10 cold keys from 10 threads complete in ~50 ms, not ~500 ms (no global lock during load).
- Put wins over in-flight load: loader for k blocks on a latch; another thread `put(k, "new")`; release loader -> `get(k)` returns "new".
- Invalidate during load: same as above with `invalidate(k)` -> the loaded value is returned to its callers but not cached.
- Load failure: loader throws -> every concurrent waiter gets the exception, nothing cached, next `get` retries.
- Null from loader -> returned as `null` / `Optional.empty()`, not cached.
- Invariant under a randomized multi-thread stress run: `size() <= capacity`, no `ConcurrentModificationException`, every value returned was either loaded for that key or put for that key.

## Code

```java
public final class LruTtlCache<K, V> {

    private record Entry<V>(V value, long expiresAtNanos) {}

    private final int capacity;
    private final long defaultTtlNanos;
    private final Function<K, V> loader;
    private final LongSupplier ticker;                       // System::nanoTime in prod, fake in tests

    private final ReentrantLock lock = new ReentrantLock();
    private final LinkedHashMap<K, Entry<V>> map;            // access-ordered => LRU
    private final ConcurrentHashMap<K, CompletableFuture<V>> inFlight = new ConcurrentHashMap<>();

    public LruTtlCache(int capacity, Duration defaultTtl, Function<K, V> loader, LongSupplier ticker) {
        if (capacity < 1) throw new IllegalArgumentException("capacity < 1");
        this.capacity = capacity;
        this.defaultTtlNanos = defaultTtl.toNanos();
        this.loader = loader;
        this.ticker = ticker;
        this.map = new LinkedHashMap<>(16, 0.75f, /*accessOrder*/ true) {
            @Override protected boolean removeEldestEntry(Map.Entry<K, Entry<V>> eldest) {
                return size() > LruTtlCache.this.capacity;
            }
        };
    }

    public V get(K key) {
        V cached = getIfPresent(key);
        if (cached != null) return cached;

        CompletableFuture<V> mine = new CompletableFuture<>();
        CompletableFuture<V> existing = inFlight.putIfAbsent(key, mine);
        if (existing != null) return await(existing);        // someone else is loading: wait, don't hit the DB

        try {
            // Re-check: another thread may have finished loading between our miss and putIfAbsent.
            V raced = getIfPresent(key);
            if (raced != null) { inFlight.remove(key, mine); mine.complete(raced); return raced; }

            V loaded = loader.apply(key);                    // ~50 ms, NO lock held
            lock.lock();
            try {
                // Only cache if nobody put/invalidated this key meanwhile (they remove our future).
                if (inFlight.remove(key, mine) && loaded != null) {
                    map.put(key, new Entry<>(loaded, ticker.getAsLong() + defaultTtlNanos));
                }
            } finally { lock.unlock(); }
            mine.complete(loaded);
            return loaded;
        } catch (RuntimeException e) {
            inFlight.remove(key, mine);
            mine.completeExceptionally(e);                   // every waiter sees the failure
            throw e;
        }
    }

    public V getIfPresent(K key) {
        lock.lock();
        try {
            Entry<V> e = map.get(key);                       // also moves key to MRU
            if (e == null) return null;
            if (ticker.getAsLong() - e.expiresAtNanos >= 0) { map.remove(key); return null; }
            return e.value;
        } finally { lock.unlock(); }
    }

    public void put(K key, V value, Duration ttl) {
        Objects.requireNonNull(value);
        lock.lock();
        try {
            inFlight.remove(key);                            // an in-flight load must not overwrite this
            map.put(key, new Entry<>(value, ticker.getAsLong() + ttl.toNanos())); // may evict eldest
        } finally { lock.unlock(); }
    }

    public void invalidate(K key) {
        lock.lock();
        try { inFlight.remove(key); map.remove(key); } finally { lock.unlock(); }
    }

    public int size() { lock.lock(); try { return map.size(); } finally { lock.unlock(); } }

    private static <V> V await(CompletableFuture<V> f) {
        try {
            return f.get(2, TimeUnit.SECONDS);               // bounded wait; DB is ~50 ms
        } catch (ExecutionException e) {
            if (e.getCause() instanceof RuntimeException re) throw re;
            throw new CompletionException(e.getCause());
        } catch (TimeoutException e) {
            throw new IllegalStateException("cache load timed out", e);
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
            throw new IllegalStateException(e);
        }
    }
}
```

## How concurrency is handled, in one place
- **Map + LRU order:** every touch of `map` is under `lock`; each critical section is O(1). No I/O under the lock.
- **Slow load:** done outside the lock. Concurrent misses on the same key are collapsed by `inFlight.putIfAbsent`: one thread loads, the rest block on its future (with a timeout). Loads for different keys run in parallel.
- **Stale-load race:** the loader's insert and `put`/`invalidate` both run under `lock` and both touch `inFlight`. `put` removes the in-flight future, so the loader's `inFlight.remove(key, mine)` returns false and it skips caching. Whichever happens first under the lock is the order of record, and a newer `put` always beats an older load.
- **Failure:** the future completes exceptionally so all waiters fail fast together; nothing is cached, so the next caller retries. (If the DB is down, add a short negative-cache or circuit breaker so every request doesn't re-hit it.)
- **Expiry:** checked lazily on read with a monotonic clock (`nanoTime`, compared by subtraction to be overflow-safe). Expired entries still occupy capacity until read or evicted as LRU; if that matters, have `put` also drop a few expired entries from the LRU head, or run a periodic sweep.
- **Thundering herd on expiry** of a hot key is already handled by single-flight. Optional: add jitter to TTLs so many keys loaded together don't expire together.

## Tests (sample)
```java
AtomicLong now = new AtomicLong();
AtomicInteger loads = new AtomicInteger();
LruTtlCache<String, String> cache = new LruTtlCache<>(2, Duration.ofSeconds(10),
        k -> { loads.incrementAndGet(); return "v-" + k; }, now::get);

@Test void evictsLeastRecentlyUsed() {
    cache.put("a", "1", Duration.ofMinutes(1)); cache.put("b", "2", Duration.ofMinutes(1));
    cache.getIfPresent("a");
    cache.put("c", "3", Duration.ofMinutes(1));
    assertNull(cache.getIfPresent("b"));
    assertEquals("1", cache.getIfPresent("a"));
    assertEquals(2, cache.size());
}

@Test void expiresExactlyAtTtl() {
    cache.put("a", "1", Duration.ofSeconds(10));
    now.set(Duration.ofSeconds(10).toNanos() - 1); assertEquals("1", cache.getIfPresent("a"));
    now.set(Duration.ofSeconds(10).toNanos());     assertNull(cache.getIfPresent("a"));
}

@RepeatedTest(100) void concurrentMissesLoadOnce() throws Exception {
    var gate = new CountDownLatch(1);
    var slow = new LruTtlCache<String, String>(100, Duration.ofMinutes(1),
        k -> { loads.incrementAndGet(); sleep(50); return "v"; }, System::nanoTime);
    var pool = Executors.newFixedThreadPool(32);
    var fs = IntStream.range(0, 100).mapToObj(i -> pool.submit(() -> { gate.await(); return slow.get("k"); })).toList();
    gate.countDown();
    for (var f : fs) assertEquals("v", f.get());
    assertEquals(1, loads.get());
}

@Test void putDuringLoadWins() throws Exception {
    var release = new CountDownLatch(1);
    var c = new LruTtlCache<String, String>(10, Duration.ofMinutes(1), k -> { await(release); return "old"; }, now::get);
    var loading = CompletableFuture.supplyAsync(() -> c.get("k"));
    waitUntilInFlight(c, "k");
    c.put("k", "new", Duration.ofMinutes(1));
    release.countDown(); loading.get();
    assertEquals("new", c.getIfPresent("k"));
}

@Test void failedLoadIsNotCachedAndIsRetried() { /* loader throws once, then succeeds */ }
```
