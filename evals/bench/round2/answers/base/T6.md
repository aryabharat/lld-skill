# In-process cache: TTL + LRU + concurrent loads

## Requirements recap and assumptions
- Fixed capacity, LRU eviction; each entry has its own TTL (passed on put, or a default for loads).
- Many threads call `get`/`put`. `get` on miss loads from a DB taking ~50 ms.
- Key concern for the slow loader: **no cache stampede** (100 threads missing on the same key must cause 1 DB call), and **no global lock held during the 50 ms load**.
- Expired entries are removed lazily on access plus by LRU pressure; an optional background sweeper is mentioned at the end.
- In production I would use Caffeine (`Caffeine.newBuilder().maximumSize(n).expireAfter(...).build(loader)`), which does all of this better (W-TinyLFU, striped buffers). Below is the core if writing it ourselves.

## Data structures
- `HashMap<K, Node>` + intrusive doubly linked list for O(1) lookup, move-to-front, and evict-from-tail. Guarded by one `ReentrantLock`; critical sections are tiny (pointer moves), never I/O.
- `ConcurrentHashMap<K, CompletableFuture<V>> inFlight` for single-flight loading: the first thread to miss installs a future, others wait on it.
- Each `Node` stores `expiresAtNanos` from `System.nanoTime()` (monotonic, immune to wall-clock changes).

Why one lock rather than lock-free: LRU requires mutating the shared list on every read, so reads are writes. A single lock with O(1) work is simple and correct; it gets contended at very high throughput, at which point the answer is striping (N segments by key hash, each its own LRU, approximate global LRU) or Caffeine's buffered approach.

## Code

```java
public final class LruTtlCache<K, V> {
    public interface Loader<K, V> { V load(K key) throws Exception; }

    private static final class Node<K, V> {
        final K key; V value; long expiresAt;
        Node<K, V> prev, next;
        Node(K key, V value, long expiresAt) { this.key = key; this.value = value; this.expiresAt = expiresAt; }
    }

    private final int capacity;
    private final long defaultTtlNanos;
    private final Loader<K, V> loader;
    private final LongSupplier nanoClock;
    private final Executor loadExecutor;

    private final Map<K, Node<K, V>> map;
    private final Node<K, V> head = new Node<>(null, null, 0); // most recent after head
    private final Node<K, V> tail = new Node<>(null, null, 0); // least recent before tail
    private final ReentrantLock lock = new ReentrantLock();
    private final ConcurrentHashMap<K, CompletableFuture<V>> inFlight = new ConcurrentHashMap<>();

    public LruTtlCache(int capacity, Duration defaultTtl, Loader<K, V> loader,
                       Executor loadExecutor, LongSupplier nanoClock) {
        if (capacity <= 0) throw new IllegalArgumentException("capacity");
        this.capacity = capacity;
        this.defaultTtlNanos = defaultTtl.toNanos();
        this.loader = loader;
        this.loadExecutor = loadExecutor;
        this.nanoClock = nanoClock;
        this.map = new HashMap<>(capacity * 4 / 3 + 1);
        head.next = tail; tail.prev = head;
    }

    /** Returns cached value, or loads it once even if many threads miss concurrently. */
    public V get(K key) {
        V v = getIfPresent(key);
        if (v != null) return v;

        CompletableFuture<V> mine = new CompletableFuture<>();
        CompletableFuture<V> existing = inFlight.putIfAbsent(key, mine);
        if (existing != null) return join(existing);          // someone else is loading

        try {
            // re-check: a load may have completed between our miss and putIfAbsent
            v = getIfPresent(key);
            if (v == null) {
                v = loader.load(key);                         // 50 ms, NO cache lock held
                if (v != null) put(key, v, defaultTtlNanos);
            }
            mine.complete(v);
            return v;
        } catch (Exception e) {
            mine.completeExceptionally(e);                    // waiters see the failure, nothing cached
            throw new CacheLoadException(key, e);
        } finally {
            inFlight.remove(key, mine);
        }
    }

    public V getIfPresent(K key) {
        lock.lock();
        try {
            Node<K, V> n = map.get(key);
            if (n == null) return null;
            if (nanoClock.getAsLong() - n.expiresAt >= 0) {   // overflow-safe comparison
                unlink(n); map.remove(key);
                return null;
            }
            moveToFront(n);
            return n.value;
        } finally { lock.unlock(); }
    }

    public void put(K key, V value, Duration ttl) { put(key, value, ttl.toNanos()); }

    private void put(K key, V value, long ttlNanos) {
        Objects.requireNonNull(key); Objects.requireNonNull(value);
        long expiresAt = nanoClock.getAsLong() + ttlNanos;
        lock.lock();
        try {
            Node<K, V> n = map.get(key);
            if (n != null) {
                n.value = value; n.expiresAt = expiresAt;
                moveToFront(n);
                return;
            }
            if (map.size() >= capacity) evictOne();
            n = new Node<>(key, value, expiresAt);
            map.put(key, n);
            addFront(n);
        } finally { lock.unlock(); }
    }

    public void invalidate(K key) {
        lock.lock();
        try { Node<K, V> n = map.remove(key); if (n != null) unlink(n); }
        finally { lock.unlock(); }
    }

    // --- under lock ---
    private void evictOne() {
        Node<K, V> victim = tail.prev;                 // least recently used
        unlink(victim); map.remove(victim.key);
    }
    private void addFront(Node<K, V> n) { n.next = head.next; n.prev = head; head.next.prev = n; head.next = n; }
    private void unlink(Node<K, V> n)   { n.prev.next = n.next; n.next.prev = n.prev; n.prev = n.next = null; }
    private void moveToFront(Node<K, V> n) { unlink(n); addFront(n); }

    private static <V> V join(CompletableFuture<V> f) {
        try { return f.join(); }
        catch (CompletionException e) { throw new CacheLoadException(null, e.getCause()); }
    }
}
```

(Eviction takes the LRU tail even if a live entry is there while an expired one sits elsewhere. Expired entries are dropped lazily on read and by the optional sweeper below; I would add an "evict expired first" scan only if measurements show expired entries crowding out live ones.)

## Concurrency, explicitly
- **Map + list consistency**: every read and write of `map` and the list happens under `lock`. All work inside is O(1), so hold time is microseconds.
- **No lock during I/O**: `loader.load` runs outside `lock`. Holding the cache lock for 50 ms would serialize every thread on every key.
- **Stampede protection**: `inFlight.putIfAbsent` elects exactly one loader per key; others `join` its future. Different keys load in parallel.
- **Load failure**: the future completes exceptionally, waiters get the error, nothing is cached, and `finally` removes the in-flight entry so the next call retries. (Optionally negative-cache "not found" for a short TTL to protect the DB from repeated misses on absent keys.)
- **Put during an in-flight load**: if a writer calls `put(k, fresh)` while a load for `k` is running, the loader's later `put` could overwrite the fresher value with stale DB data. Fix: keep a per-key version (or have `invalidate`/`put` remove the in-flight future and the loader only installs its value if its future is still the registered one: `inFlight.remove(key, mine)` returning true before `put`). Worth doing if writes and reads of the same key race in practice.
- **Timeouts**: waiters should use `f.get(timeout)` so a hung DB call does not pin every request thread forever; the loader thread itself needs a DB query timeout.
- **Clock**: `System.nanoTime` is monotonic; compare with subtraction (`now - expiresAt >= 0`) to be overflow-safe. Injected `LongSupplier` makes TTL testable without sleeping.

## Optional additions
- Background sweeper (`ScheduledExecutorService`, every few seconds) removing expired entries from the tail region, so expired-but-unread entries do not occupy capacity for long.
- Refresh-ahead: if an entry is within X% of its TTL when read, return it and trigger an async reload via `loadExecutor`, so hot keys never block on the 50 ms load.
- Stats: hits, misses, loads, load failures, evictions.

## Tests
- Capacity 2: put a, b, get a, put c -> b evicted, a and c present.
- TTL with a fake clock: present at ttl-1ns, absent at ttl; expired entry does not count as a hit.
- Updating an existing key refreshes value, TTL and recency, and does not evict.
- Stampede: 100 threads, latch-start, `get("k")` with a loader that sleeps 50 ms and counts calls -> exactly 1 load, all 100 get the value.
- Different keys load in parallel: 10 keys x slow loader complete in ~50 ms, not ~500 ms.
- Loader exception: all waiters get the exception, nothing cached, next call retries.
- Stress: many threads random get/put/invalidate for a few seconds; then assert `map.size() <= capacity` and list length == map size (walk the list under the lock in a test-only method).
