# Parking lot: fee calculation and spot allocation

## Assumptions
- Single process owns allocation (one service instance per lot, or a DB row lock if multiple instances; covered at the end).
- Spot sizes: SMALL (bike), MEDIUM (car), LARGE (truck). A vehicle may take its own size or larger (bike can take car spot if no small spot is free). Configurable.
- Fee is computed at exit from the ticket's entry time and exit time. A stay crossing weekday/weekend boundaries is charged per hour slice, each slice priced by its own day type.
- Money is `BigDecimal` (or long paise), never `double`.

## Domain

```java
enum VehicleType { BIKE, CAR, TRUCK }
enum SpotSize   { SMALL, MEDIUM, LARGE }

record Vehicle(String plate, VehicleType type) {}

final class ParkingSpot {
    private final String id;
    private final int floor;
    private final SpotSize size;
    ParkingSpot(String id, int floor, SpotSize size) { this.id = id; this.floor = floor; this.size = size; }
    String id() { return id; } int floor() { return floor; } SpotSize size() { return size; }
}

record Ticket(String id, Vehicle vehicle, ParkingSpot spot, Instant entryTime) {}
```

## Fee calculation: a rule pipeline, not an if-chain

New rules (night rate, member discount, event surcharge) arrive regularly, so each rule is its own class and the calculator composes them. Two kinds of rules:
- **Base rate**: how much one hour (slice) costs, depending on vehicle type and day type. Data-driven table, not code.
- **Adjustments**: modify the running total (surcharge, discount), applied in a defined order.

```java
record PricingContext(Ticket ticket, Instant exitTime, Optional<Member> member, ZoneId zone) {}

interface RateTable {                       // base price per hour
    Money hourlyRate(VehicleType type, DayType dayType);
}
enum DayType { WEEKDAY, WEEKEND }

interface FeeAdjustment {                    // night rate, member discount, event surcharge...
    int order();                             // surcharges before discounts, caps last
    Money apply(Money current, PricingContext ctx, FeeBreakdown breakdown);
}

final class FeeCalculator {
    private final RateTable rates;
    private final List<FeeAdjustment> adjustments;   // sorted once by order()

    FeeCalculator(RateTable rates, List<FeeAdjustment> adjustments) {
        this.rates = rates;
        this.adjustments = adjustments.stream()
            .sorted(Comparator.comparingInt(FeeAdjustment::order)).toList();
    }

    FeeBreakdown calculate(PricingContext ctx) {
        FeeBreakdown b = new FeeBreakdown();
        Money total = Money.ZERO;
        ZonedDateTime t = ctx.ticket().entryTime().atZone(ctx.zone());
        ZonedDateTime end = ctx.exitTime().atZone(ctx.zone());
        if (!end.isAfter(t)) throw new IllegalArgumentException("exit before entry");
        // charge per started hour; each hour priced by the day it starts in
        while (t.isBefore(end)) {
            DayType day = isWeekend(t.getDayOfWeek()) ? DayType.WEEKEND : DayType.WEEKDAY;
            Money hour = rates.hourlyRate(ctx.ticket().vehicle().type(), day);
            total = total.plus(hour);
            b.addLine("base " + day + " " + t, hour);
            t = t.plusHours(1);
        }
        for (FeeAdjustment a : adjustments) total = a.apply(total, ctx, b);
        b.setTotal(total.max(Money.ZERO));
        return b;
    }
    private static boolean isWeekend(DayOfWeek d) { return d == DayOfWeek.SATURDAY || d == DayOfWeek.SUNDAY; }
}

final class InMemoryRateTable implements RateTable {
    private final Map<VehicleType, Map<DayType, Money>> table;   // loaded from config
    InMemoryRateTable(Map<VehicleType, Map<DayType, Money>> table) { this.table = table; }
    public Money hourlyRate(VehicleType v, DayType d) {
        Money m = table.getOrDefault(v, Map.of()).get(d);
        if (m == null) throw new IllegalStateException("no rate for " + v + "/" + d);
        return m;
    }
}

// Example future rule: drop-in, no change to FeeCalculator
final class MemberDiscount implements FeeAdjustment {
    private final BigDecimal pct;
    MemberDiscount(BigDecimal pct) { this.pct = pct; }
    public int order() { return 200; }
    public Money apply(Money cur, PricingContext ctx, FeeBreakdown b) {
        if (ctx.member().isEmpty()) return cur;
        Money off = cur.times(pct);
        b.addLine("member discount", off.negate());
        return cur.minus(off);
    }
}
```

`FeeBreakdown` records each line, so the receipt and support can explain the charge. Night rate fits as either a different `RateTable` lookup (if it replaces the hourly price) or an adjustment per slice; if it is per-slice, extend `RateTable.hourlyRate` to take the slice start time instead of only `DayType`. I would make that signature `hourlyRate(VehicleType, ZonedDateTime sliceStart)` from day one, since it costs nothing and is the most likely change.

## Spot allocation: concurrency-safe

Requirement: two gates requesting at the same instant must never get the same spot, and allocation must be fast.

Design: per floor, per size, a lock-free queue of free spots. Taking a spot is `poll()`, which is atomic, so two threads can never receive the same spot. Release is `offer()`.

```java
interface SpotAllocationStrategy {          // nearest floor first, or spread load, etc.
    List<SpotSize> candidateSizes(VehicleType t);   // e.g. BIKE -> SMALL, MEDIUM, LARGE
}

final class ParkingLot {
    private final List<Floor> floors;                  // ordered by preference (lowest first)
    private final SpotAllocationStrategy strategy;
    private final ConcurrentMap<String, Ticket> active = new ConcurrentHashMap<>();
    private final ConcurrentMap<String, Boolean> parkedPlates = new ConcurrentHashMap<>();
    private final Clock clock;
    private final FeeCalculator fees;

    Optional<Ticket> park(Vehicle v) {
        if (parkedPlates.putIfAbsent(v.plate(), Boolean.TRUE) != null)
            throw new IllegalStateException("vehicle already inside: " + v.plate());
        for (SpotSize size : strategy.candidateSizes(v.type())) {
            for (Floor f : floors) {
                ParkingSpot s = f.tryTake(size);
                if (s != null) {
                    Ticket t = new Ticket(UUID.randomUUID().toString(), v, s, clock.instant());
                    active.put(t.id(), t);
                    return Optional.of(t);
                }
            }
        }
        parkedPlates.remove(v.plate());
        return Optional.empty();                         // lot full for this vehicle
    }

    FeeBreakdown exit(String ticketId, Optional<Member> member) {
        Ticket t = active.remove(ticketId);              // atomic: second exit with same ticket gets null
        if (t == null) throw new IllegalArgumentException("unknown or already used ticket");
        FeeBreakdown fee = fees.calculate(new PricingContext(t, clock.instant(), member, ZoneId.of("Asia/Kolkata")));
        floorOf(t.spot()).release(t.spot());
        parkedPlates.remove(t.vehicle().plate());
        return fee;
    }
}

final class Floor {
    private final int number;
    private final Map<SpotSize, ConcurrentLinkedQueue<ParkingSpot>> free = new EnumMap<>(SpotSize.class);
    Floor(int number, List<ParkingSpot> spots) {
        this.number = number;
        for (SpotSize s : SpotSize.values()) free.put(s, new ConcurrentLinkedQueue<>());
        spots.forEach(sp -> free.get(sp.size()).add(sp));
    }
    ParkingSpot tryTake(SpotSize size) { return free.get(size).poll(); }   // atomic
    void release(ParkingSpot s)        { free.get(s.size()).offer(s); }
    int freeCount(SpotSize size)       { return free.get(size).size(); }    // O(n), display only
}
```

Why this and not `synchronized park()`: a global lock serializes all gates for no reason; the queue gives per-size, per-floor atomicity with no lock. The `EnumMap` is built in the constructor and never mutated after, so it is safely published via the final field.

Payment ordering: if payment can fail, `exit` should compute the fee, take payment, then release the spot. Split it into `quote(ticketId)` and `complete(ticketId, paymentRef)`, with `complete` doing the atomic `remove`.

Multiple service instances: in-memory queues are no longer correct. Use the DB as the source of truth: `UPDATE spots SET ticket_id=? WHERE id = (SELECT id FROM spots WHERE size=? AND ticket_id IS NULL ORDER BY floor LIMIT 1 FOR UPDATE SKIP LOCKED)`. `SKIP LOCKED` lets concurrent gates grab different rows without blocking.

## Tests

Fee:
- Car, 2 hours on a Wednesday = 2 x weekday car rate.
- Truck, Friday 23:00 to Saturday 01:00 = 1 weekday hour + 1 weekend hour.
- 61 minutes charges 2 hours (started-hour rule); 0 minutes / exit before entry rejected.
- Missing rate in table fails loudly.
- Adjustments run in `order()` sequence; member discount applied after event surcharge; total never negative.
- Adding a new `FeeAdjustment` needs no change to `FeeCalculator` (test with a stub rule).
- Use a fixed `Clock` and explicit `ZoneId` everywhere; no `Instant.now()`.

Allocation:
- Bike falls back to MEDIUM when SMALL is full; truck never gets SMALL/MEDIUM.
- Lot full returns empty and does not leave the plate marked as parked.
- Same plate cannot park twice; same ticket cannot exit twice.
- Release makes the spot available again.
- Concurrency: N spots, 8 threads x many park calls released by a `CountDownLatch` at once; assert exactly N tickets issued and all spot ids distinct. Then concurrent park/exit churn for a few seconds and assert free + occupied == capacity at the end.
