# T1 Parking lot: fee calculation and spot allocation

## Scope

Kept: issue a ticket and a spot at an entry gate, compute the fee and free the spot at exit, pricing by vehicle type and weekday/weekend, room for further pricing rules, correct behaviour when several gates ask at once.

`skipped: payment, reservations, display boards, per-floor routing, persistence; add when requested. Night rate / member discount / event surcharge are not built, but each is one entry in the rule list below.`

Assumptions:
- Spot sizes: SMALL, MEDIUM, LARGE. A bike fits any size, a car fits MEDIUM or LARGE, a truck fits only LARGE. Allocation uses the smallest size that fits first, then the lowest floor and spot number.
- Billing: each started hour is charged at the rate for that hour's day (weekday or weekend). A stay from Friday 23:00 to Saturday 01:00 is one weekday hour plus one weekend hour.
- The lot runs in one process. Several gate threads call the same `ParkingLot`.

## The two hard questions

1. **Allocation:** which structure gives the "next free spot of size S", and what happens when two gates ask together? Answer: one `ConcurrentSkipListSet<Spot>` of free spots per size, ordered by (floor, number). `pollFirst()` removes and returns the first element in one atomic step, so two gates can never get the same spot, and no lock is needed. Cost O(log n).
2. **Pricing growth:** the request names three more rules. That makes this a repeat request of the same kind, so the varying logic leaves the calculator and is passed in as data: a base rate table plus an **ordered** list of adjustments. The order matters here (a surcharge applied before a percentage discount gives a different result from one applied after), so the list order is the contract. It is a pipeline where every step runs, not a first-match rule set.

Time is data: the calculator receives entry and exit instants plus a `ZoneId`. Nothing in the domain reads the clock; the gate reads it once and passes it in.

## Code (critical path)

```java
enum VehicleType { BIKE, CAR, TRUCK }
enum SpotSize { SMALL, MEDIUM, LARGE }
enum DayType { WEEKDAY, WEEKEND }

record Spot(int floor, int number, SpotSize size) {}
record Ticket(String id, VehicleType vehicle, Spot spot, Instant entry, String memberId /* nullable */) {}
record Receipt(Ticket ticket, Instant exit, BigDecimal fee) {}

/** Context that every pricing step can read. Built once per exit. */
record PricingContext(Ticket ticket, Instant exit, ZoneId zone) {}

/** One step of the price pipeline: takes the running amount and returns the new one. */
@FunctionalInterface
interface PricingStep {
    BigDecimal apply(PricingContext ctx, BigDecimal running);
}

final class FeeCalculator {
    private final Map<VehicleType, Map<DayType, BigDecimal>> hourlyRates;
    private final List<PricingStep> adjustments;   // order is the contract: surcharges before discounts

    FeeCalculator(Map<VehicleType, Map<DayType, BigDecimal>> hourlyRates, List<PricingStep> adjustments) {
        for (VehicleType v : VehicleType.values())
            for (DayType d : DayType.values())
                if (hourlyRates.getOrDefault(v, Map.of()).get(d) == null)
                    throw new IllegalArgumentException("missing rate for " + v + "/" + d);
        this.hourlyRates = hourlyRates;
        this.adjustments = List.copyOf(adjustments);
    }

    BigDecimal fee(PricingContext ctx) {
        BigDecimal amount = base(ctx);
        for (PricingStep step : adjustments) amount = step.apply(ctx, amount);
        return amount.max(BigDecimal.ZERO).setScale(2, RoundingMode.HALF_UP);
    }

    private BigDecimal base(PricingContext ctx) {
        Instant entry = ctx.ticket().entry();
        if (ctx.exit().isBefore(entry)) throw new IllegalArgumentException("exit before entry: " + ctx);
        long minutes = Duration.between(entry, ctx.exit()).toMinutes();
        long startedHours = Math.max(1, (minutes + 59) / 60);           // minimum one hour
        BigDecimal total = BigDecimal.ZERO;
        for (long h = 0; h < startedHours; h++) {
            ZonedDateTime hourStart = entry.plus(Duration.ofHours(h)).atZone(ctx.zone());
            total = total.add(hourlyRates.get(ctx.ticket().vehicle()).get(dayType(hourStart)));
        }
        return total;
    }

    static DayType dayType(ZonedDateTime t) {
        DayOfWeek d = t.getDayOfWeek();
        return (d == DayOfWeek.SATURDAY || d == DayOfWeek.SUNDAY) ? DayType.WEEKEND : DayType.WEEKDAY;
    }
}
```

Allocation and the gate operations:

```java
/**
 * Thread-safe: any number of gate threads may call park/exit concurrently.
 * Guarantees: a spot is held by at most one ticket; a ticket exits at most once.
 * No ordering between gates: two cars that arrive together get two different spots, in no promised order.
 */
final class ParkingLot {
    private static final Map<VehicleType, List<SpotSize>> FITS = Map.of(
        VehicleType.BIKE,  List.of(SpotSize.SMALL, SpotSize.MEDIUM, SpotSize.LARGE),
        VehicleType.CAR,   List.of(SpotSize.MEDIUM, SpotSize.LARGE),
        VehicleType.TRUCK, List.of(SpotSize.LARGE));

    private static final Comparator<Spot> NEAREST =
        Comparator.comparingInt(Spot::floor).thenComparingInt(Spot::number);

    private final Map<SpotSize, ConcurrentSkipListSet<Spot>> free = new EnumMap<>(SpotSize.class);
    private final ConcurrentHashMap<String, Ticket> active = new ConcurrentHashMap<>();
    private final FeeCalculator calculator;
    private final ZoneId zone;

    ParkingLot(Collection<Spot> spots, FeeCalculator calculator, ZoneId zone) {
        for (SpotSize s : SpotSize.values()) free.put(s, new ConcurrentSkipListSet<>(NEAREST));
        for (Spot s : spots) free.get(s.size()).add(s);   // the EnumMap itself is never written after this
        this.calculator = calculator;
        this.zone = zone;
    }

    /** Empty when no compatible spot is free. `now` is read once by the gate. */
    Optional<Ticket> park(VehicleType vehicle, String memberId, Instant now) {
        for (SpotSize size : FITS.get(vehicle)) {
            Spot spot = free.get(size).pollFirst();        // atomic claim: no two gates get the same spot
            if (spot != null) {
                Ticket t = new Ticket(UUID.randomUUID().toString(), vehicle, spot, now, memberId);
                active.put(t.id(), t);
                return Optional.of(t);
            }
        }
        return Optional.empty();
    }

    Receipt exit(String ticketId, Instant now) {
        Ticket t = active.remove(ticketId);                 // atomic: a second exit with the same ticket gets null
        if (t == null) throw new IllegalArgumentException("unknown or already used ticket: " + ticketId);
        BigDecimal fee;
        try {
            fee = calculator.fee(new PricingContext(t, now, zone));
        } catch (RuntimeException e) {
            active.put(t.id(), t);                          // keep the ticket valid if pricing fails
            throw e;
        }
        free.get(t.spot().size()).add(t.spot());            // free the spot only after the ticket is closed
        return new Receipt(t, now, fee);
    }
}
```

Why no lock: each step that must be exclusive is one atomic call on one structure (`pollFirst` for the spot, `remove` for the ticket). Between `pollFirst` and `active.put` the spot is out of the free set and the ticket is not yet visible; no other caller can observe or act on that gap, so it is safe. If a later feature needs two structures to change together (for example a reservation that holds a spot and a ticket in one step), add one lock around that step.

`ponytail: one free set per size for the whole lot; per-floor sets if gates must prefer their own floor. In-memory only; with several lot servers the claim moves to the database (UPDATE spots SET ticket_id=? WHERE id=? AND ticket_id IS NULL).`
