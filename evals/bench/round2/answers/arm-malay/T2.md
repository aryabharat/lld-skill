# T2 Draw after 50 moves without a win

## Decision

"Draw" now has two causes: the board is full, or 50 moves were made. Both decide one action, so they become **one condition in one place**, checked after every win check. That order is the rule: if the 50th move completes a line, the result is a win, not a draw.

Where the pieces live:
- **The move count** is a fact about the board's history. `Board` already knows who moved last, so it records moves. `moveCount()` goes on `Board`, derived from what it already stores (number of placed marks, or the size of its move list). No counter in `GameEngine` and no counter in the caller: either would miss moves that do not go through it.
- **The limit 50** is a rule of this game, not a fact about the board. It goes on `GameEngine` as a constructor value with 50 as the default, so a test can use a small limit.

"Without a win" needs no extra state: any win ends the game, so while the game is in progress the moves made so far are all moves without a win.

## Change

```java
class GameEngine {
  static final int DEFAULT_MOVE_LIMIT = 50;
  private final int moveLimit;

  GameEngine() { this(DEFAULT_MOVE_LIMIT); }

  GameEngine(int moveLimit) {
    if (moveLimit < 1) throw new IllegalArgumentException("moveLimit must be >= 1, got " + moveLimit);
    this.moveLimit = moveLimit;
  }

  GameState getState(Board b) {
    if (rowWin(b)) return GameState.win(b.lastPlayer());
    if (colWin(b)) return GameState.win(b.lastPlayer());
    if (diagWin(b)) return GameState.win(b.lastPlayer());
    if (revDiagWin(b)) return GameState.win(b.lastPlayer());
    if (b.isFull() || b.moveCount() >= moveLimit) return GameState.draw();   // wins are checked first
    return GameState.inProgress();
  }
}
```

```java
class Board {
  // existing fields ...
  private int moveCount;            // only if Board does not already keep a move list; then return its size

  void place(int row, int col, Player p) {
    // existing validation and write ...
    moveCount++;                    // in the one method that places a mark, so no path can skip it
  }

  int moveCount() { return moveCount; }
}
```

If `Board` has a copy method (for an AI look-ahead), copy `moveCount` there too; otherwise a copied board restarts the count at zero.

Note: on a standard 3x3 board the board fills after 9 moves, so the limit only matters on larger boards. That is fine; the rule is generic.

Not done on purpose: the four win checks are independent "check, return" blocks and could become a list of rule functions. This change does not add a win check, so they stay as they are. `skipped: win-rule list, add when the next win rule arrives.`

## Tests (through `getState`, with a small limit)

```java
@Test void drawWhenMoveLimitReachedWithoutWin() {
  GameEngine engine = new GameEngine(4);
  Board b = boardWithMoves(4, /* no line */);
  assertEquals(GameState.draw(), engine.getState(b));
}

@Test void inProgressOneMoveBeforeLimit() {
  GameEngine engine = new GameEngine(4);
  assertEquals(GameState.inProgress(), engine.getState(boardWithMoves(3)));
}

@Test void winOnTheLimitMoveIsAWinNotADraw() {
  GameEngine engine = new GameEngine(5);
  Board b = boardWhereFifthMoveCompletesARow();
  assertEquals(GameState.win(b.lastPlayer()), engine.getState(b));
}

@Test void fullBoardBeforeLimitIsStillADraw() {
  assertEquals(GameState.draw(), new GameEngine(50).getState(fullBoardNoWin3x3()));
}

@Test void defaultLimitIsFifty() {
  GameEngine engine = new GameEngine();
  assertEquals(GameState.inProgress(), engine.getState(largeBoardWithMoves(49)));
  assertEquals(GameState.draw(),       engine.getState(largeBoardWithMoves(50)));
}
```
