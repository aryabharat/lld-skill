# T6 In-process cache: per-entry TTL, LRU at fixed capacity, concurrent, slow loader

In production I would use Caffeine (`maximumSize` + `expireAfter` + `AsyncLoadingCache`), which does all of this. Below is the core as it would be built by hand.

## Guarantees (written at the top of the class)

```
// get: returns a value no older than its TTL. Concurrent gets of one missing key cause one load.
// put: after put(k, v) returns, every later get(k) on any thread sees v (or a newer put) until it expires
//      or is evicted. A load that was in flight when put ran does not overwrite v.
// Expiry is from write/load time, set once; reads do not extend it.
// Eviction when full: expired entries first, then the least recently used.
// A failed load is not cached; the next get tries again.
// skipped: refresh-ahead, negative caching of "not found", write-through, stats; add when requested.
```

## The decisions

1. **Two independent orders.** LRU order changes on every read; expiry order is fixed per entry and differs per entry. One structure cannot serve both, so:
   - `LinkedHashMap` in access order: key -> entry; gives LRU order and O(1) eldest.
   - `PriorityQueue<ExpiryRef>` ordered by expiry time: lets eviction drop expired entries first without a scan. Stale heap refs (entry overwritten or removed) are skipped through a `live` flag on the entry, and compacted when the heap grows past 2x capacity.
2. **One lock for the step that touches both structures.** An access-order `LinkedHashMap` mutates on `get`, so reads need the lock too. Everything under the lock is O(log n) in-memory work, never I/O.
3. **The 50 ms load never runs under the lock** and is collapsed: a `ConcurrentHashMap<K, CompletableFuture<V>>` of in-flight loads. The first caller for a missing key creates an un-started future with `putIfAbsent`; only the winner starts the load. The others attach to the same future. (With 50 ms loads and many request threads, a cold hot key would otherwise send one query per thread.)
4. **Put vs an in-flight load.** A load that started before a `put` must not overwrite the newer value when it returns. `put` removes the in-flight entry under the cache lock; the loader installs its result only if `inflight.remove(key, itsOwnFuture)` succeeds under the same lock.
5. **Time is injected** (`LongSupplier` of millis) and read once per operation.

## Code

```java
public final class TtlLruCache<K, V> {

    /** Guarded by lock. `live` is false once the entry is replaced, expired or evicted. */
    private static final class Entry<V> {
        final V value; final long expiresAt; boolean live = true;
        Entry(V value, long expiresAt) { this.value = value; this.expiresAt = expiresAt; }
    }
    private record ExpiryRef<K, V>(K key, Entry<V> entry) {}

    private final int capacity;
    private final long defaultTtlMs;
    private final Function<K, V> loader;          // slow: ~50 ms
    private final Executor loadPool;              // owned by the cache; loads never run under the lock
    private final LongSupplier clock;

    private final ReentrantLock lock = new ReentrantLock();
    // guarded by lock
    private final LinkedHashMap<K, Entry<V>> entries = new LinkedHashMap<>(16, 0.75f, true);  // access order = LRU
    private final PriorityQueue<ExpiryRef<K, V>> expiryQueue =
        new PriorityQueue<>(Comparator.comparingLong(r -> r.entry().expiresAt));
    // concurrent map; removed under the lock wherever it must agree with `entries`
    private final ConcurrentHashMap<K, CompletableFuture<V>> inflight = new ConcurrentHashMap<>();

    public TtlLruCache(int capacity, long defaultTtlMs, Function<K, V> loader, Executor loadPool, LongSupplier clock) {
        if (capacity < 1) throw new IllegalArgumentException("capacity must be >= 1, got " + capacity);
        if (defaultTtlMs < 1) throw new IllegalArgumentException("ttl must be >= 1 ms, got " + defaultTtlMs);
        this.capacity = capacity; this.defaultTtlMs = defaultTtlMs;
        this.loader = loader; this.loadPool = loadPool; this.clock = clock;
    }

    /** Non-blocking: a hit returns a completed future; a miss returns the shared load future. */
    public CompletableFuture<V> getAsync(K key) {
        long now = clock.getAsLong();                          // read once
        lock.lock();
        try {
            Entry<V> e = entries.get(key);                     // also marks key most-recently used
            if (e != null) {
                if (now < e.expiresAt) return CompletableFuture.completedFuture(e.value);
                remove(key);                                   // expired
            }
        } finally { lock.unlock(); }
        return loadCollapsed(key);
    }

    /** For thread-per-request callers. */
    public V get(K key) {
        try { return getAsync(key).join(); }
        catch (CompletionException e) { throw (e.getCause() instanceof RuntimeException r) ? r : e; }
    }

    public void put(K key, V value) { put(key, value, defaultTtlMs); }

    public void put(K key, V value, long ttlMs) {
        if (ttlMs < 1) throw new IllegalArgumentException("ttl must be >= 1 ms, got " + ttlMs);
        Objects.requireNonNull(value, "value");
        long now = clock.getAsLong();
        lock.lock();
        try {
            inflight.remove(key);                              // an older in-flight load must not overwrite this
            install(key, value, now + ttlMs, now);
        } finally { lock.unlock(); }
    }

    public void invalidate(K key) {
        lock.lock();
        try { inflight.remove(key); remove(key); }
        finally { lock.unlock(); }
    }

    // ---- internals ----

    private CompletableFuture<V> loadCollapsed(K key) {
        CompletableFuture<V> mine = new CompletableFuture<>();          // created, not started
        CompletableFuture<V> existing = inflight.putIfAbsent(key, mine);
        if (existing != null) return existing;                          // attach to the running load
        loadPool.execute(() -> {
            V value;
            try {
                value = loader.apply(key);
                if (value == null) throw new NoSuchElementException("no value for " + key);
            } catch (Throwable t) {
                inflight.remove(key, mine);                             // a failed load is not cached
                mine.completeExceptionally(t);
                return;
            }
            long now = clock.getAsLong();
            lock.lock();
            try {
                if (inflight.remove(key, mine))                        // false: put/invalidate superseded this load
                    install(key, value, now + defaultTtlMs, now);
            } finally { lock.unlock(); }
            mine.complete(value);                                      // complete outside the lock
        });
        return mine;
    }

    /** The only place that adds. Caller holds the lock. */
    private void install(K key, V value, long expiresAt, long now) {
        remove(key);                                                   // replaced entry's heap ref becomes stale
        if (entries.size() >= capacity) evictOne(now);
        Entry<V> e = new Entry<>(value, expiresAt);
        entries.put(key, e);
        expiryQueue.add(new ExpiryRef<>(key, e));
        if (expiryQueue.size() > 2 * capacity) compactExpiryQueue();   // bound stale refs
    }

    /** Caller holds the lock. */
    private void remove(K key) {
        Entry<V> old = entries.remove(key);
        if (old != null) old.live = false;
    }

    /** Caller holds the lock. Expired entries first, then the least recently used one. */
    private void evictOne(long now) {
        while (!expiryQueue.isEmpty() && expiryQueue.peek().entry().expiresAt <= now) {
            ExpiryRef<K, V> ref = expiryQueue.poll();
            if (ref.entry().live) remove(ref.key());                   // stale refs are just dropped
        }
        if (entries.size() >= capacity) {
            Iterator<Map.Entry<K, Entry<V>>> it = entries.entrySet().iterator();  // least recent first
            Map.Entry<K, Entry<V>> eldest = it.next();
            eldest.getValue().live = false;
            it.remove();
        }
    }

    private void compactExpiryQueue() {
        expiryQueue.removeIf(r -> !r.entry().live);
    }
}
```

Liveness is a flag on the entry object, not a lookup in `entries`: a `get` on an access-order `LinkedHashMap` reorders, so eviction must not read through it.

## Concurrency summary

| Path | Thread | Lock held | I/O |
|---|---|---|---|
| hit | caller | yes, O(1) | none |
| miss, first caller | caller registers future; load on `loadPool` | no | 50 ms on `loadPool` |
| miss, other callers | caller | no | none, attaches to the future |
| install after load | `loadPool` | yes, O(log n) | none |
| put / invalidate | caller | yes | none |

`ponytail: one lock for the whole cache; every get serialises on it. Fine to roughly a few million ops/s on one lock. If profiling shows contention, shard into N independent caches by hash(key) % N (LRU becomes approximate per shard), or move to Caffeine.`

Wrong shapes avoided:
- `inflight.putIfAbsent(key, supplyAsync(() -> loader.apply(key)))` would start a load for every caller, because the argument runs before the call.
- Loading inside the lock would make every thread wait 50 ms behind one miss.
- Leaving a failed future in `inflight` would return the same failure forever.
- Refreshing `expiresAt` on read would let a hot key never expire.

## Tests

All with a settable clock (`AtomicLong now; clock = now::get`), a direct executor or a small pool, and a fake loader that counts calls and can be held on a latch.

- `missLoadsThenHits`: get "a" twice, loader called once, both return the value.
- `expiresAfterTtl`: put with TTL 100 at t=0; at t=99 hit; at t=100 reload from loader.
- `perEntryTtl`: two keys with TTL 10 and 1000; at t=50 only the first reloads.
- `lruEvictsLeastRecentlyUsed`: capacity 2; put a, put b, get a, put c: b is gone, a and c stay.
- `expiredEvictedBeforeLru`: capacity 2; a (TTL 10), b (TTL 1000); touch a last; at t=20 put c: a is evicted (expired), not b.
- `concurrentMissesLoadOnce`: loader blocks on a latch; 50 threads call `getAsync("k")` together; release; loader count == 1 and all 50 futures return the value.
- `putDuringLoadWins`: loader held; get("k") starts a load; put("k", "new"); release loader with "old"; get("k") returns "new".
- `failedLoadNotCached`: loader throws once, then succeeds; first future fails, second get loads again.
- `randomisedHistory`: 8 threads, 100 keys, puts of increasing versions per key mixed with gets; per key, values a thread observes never go backwards. Remove the lock once and confirm the test fails.
